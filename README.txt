GITHUB UPDATE
-------------
1. ZIP entpacken.
2. In deinem GitHub Repository die vorhandenen Dateien durch ALLE Dateien aus diesem Ordner ersetzen/hochladen.
3. Wichtig: Auch den kompletten Ordner assets hochladen.
4. Commit changes.
5. GitHub Pages aktualisiert die Seite automatisch nach wenigen Minuten.
